# DNS/도메인 검증 규칙 (30개 항목)

## 🌐 도메인 기본 설정 (10개)

### 정규식 검증 패턴

```regex
# 도메인명
^[a-z0-9]([a-z0-9-]{0,61}[a-z0-9])?(\.[a-z0-9]([a-z0-9-]{0,61}[a-z0-9])?)*$

# IP 주소
^[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}$

# 상태
^(Active|Inactive|Expired)$

# 잠금 상태
^(Locked|Unlocked)$

# 설정 상태
^(Enabled|Disabled)$
```
